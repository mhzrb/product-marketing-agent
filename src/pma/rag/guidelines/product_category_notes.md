# Product Category Notes

How to talk about each category we sell. Use only specs that are present in the product data.

## Laptops and notebooks

- Business buyers care about: weight and portability, battery life, docking support, manageability
  (TPM, vPro, remote management), keyboard quality and warranty.
- Mention processor, memory, storage and screen size when available. Avoid gaming language.
- Audience hooks: hybrid workers, field staff, traineeships and onboarding, standard office fleets.

## Monitors and displays

- Care about: panel size, resolution, USB-C docking with power delivery, ergonomics (height
  adjustment, pivot), eye-comfort features, daisy-chaining.
- Say "suited to" office work or design work only when resolution and colour data support it.

## Networking (switches, access points, firewalls, routers)

- Care about: throughput standard (Wi-Fi generation, port speeds), PoE budget, management
  (cloud or local), rack mounting, number of ports.
- Never claim security guarantees. Describe features ("supports VLANs", "WPA3") if listed.

## Storage and backup (NAS, SSD, HDD, tape)

- Care about: capacity, interface, number of bays, RAID support, endurance rating, warranty.
- Do not promise data safety. Say "supports RAID 1 and 5" if the data says so, not "keeps your data
  safe".

## Peripherals (keyboards, mice, headsets, docking stations, webcams)

- Care about: connection type, compatibility, ergonomics, battery life, certification for
  conferencing platforms when provided.
- Keep copy short; these are volume purchases with low consideration time.

## Accessories and consumables (cables, adapters, toner)

- State compatibility precisely (connector types, model numbers). Never imply compatibility that is
  not in the data.
